# 运行手册与测试

## 启动

```bash
python3 -m scripts.seed                    # 重置并写入演示数据
python3 -m backend.server 8000             # API + Web（渲染默认内联执行）
PORT=8000 ./run_dev.sh                     # 等价一键脚本

# 前后台分离部署：
WORKBENCH_INLINE=0 python3 -m backend.server 8000
python3 -m worker                          # 轮询队列并渲染
```

环境变量：`WORKBENCH_DB`（SQLite 路径，默认 data/workbench.db）、
`WORKBENCH_STORAGE`（blob 与产出根目录，默认 storage/）、`WORKBENCH_INLINE`（0/1）。

## 手工走查建议（浏览器）

1. 用 bob 登录，首页"恢复上次项目"→ 打开种子项目；切到 carol 再恢复 → 看到 403 提示。
2. 时间线把大厅镜头改成私有/挂大床房 → 保存被 422 拦截。
3. 勾选快手但卡片没有快手坐标 → 检查报 `OVERLAY_NO_CHANNEL_GEOMETRY`。
4. 用 bob 改字幕保存；另开无痕窗以 evelyn 登录基于旧版本保存 → 409 冲突提示。
5. 素材库里"撤回授权/标记来源失效"后回到项目发布 → 422 对应错误。
6. 上传任意文件（会随机失败一次）→ 再点上传继续 → 完成后拿到 sha256 登记素材。
7. 发布成功后打开导出页：SRT/镜头清单/接触印片/故事板 + 冻结快照。
8. alice 去修订入住规则后，bob 重新发布旧项目 → `RULE_REVISION_STALE`。

## 生产化要点（当前刻意保持简单的部分）

* 认证：目前用 `X-User-Id` 演示，生产替换为会话/OAuth 中间件即可，权限逻辑不变。
* 队列：`jobs` 表 + 轮询/`claim_next_job` 可替换成 Redis/RQ、SQS 等；
  "工作器复检"语义必须保留。
* 视频渲染：ffmpeg 路径已预留（concat + scale/crop），占位字节环境下降级 SVG 预览。
* 存储：本地内容寻址目录可替换为 S3 兼容实现（保持 `blob_exists/open_blob/put_blob`）。
* 审计：规则修订、授权撤回均带操作人与时间；需要更强审计可追加 append-only 事件表。
